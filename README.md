## 🚀 Deployment Options

### 1. GitHub Pages
1. Push this directory to your GitHub account as repository `shivaganesh-portfolio` (or `shivaganesh22.github.io`):
   ```bash
   git add .
   git commit -m "feat: launch advanced portfolio"
   git remote add origin https://github.com/shivaganesh22/shivaganesh-portfolio.git
   git branch -M main
   git push -u origin main
   ```
2. In GitHub repository **Settings → Pages**, select branch `main` and root `/`.
3. Under Custom Domain, add `shivaganesh.net`.

### 2. Vercel
Deploy with 1-click via Vercel CLI:
```bash
npx vercel
```

### 3. Local Development
Run the local server:
```bash
python -m http.server 8080
```
Open [http://localhost:8080](http://localhost:8080) in your browser.
