## Selected work

### RSGMovies · Multi-platform streaming

RSGMovies is a movie streaming and download platform for web, Android TV, and mobile. It brings together movie listings and viewing links from Movierulz, TamilMV, iBomma, MovieBlast, iStreamflare, and MovierulzHD, using BeautifulSoup to collect and parse source pages. From a title, users can open available streams or downloads, send a movie to Seedr for cloud access at different resolutions, search torrents, or use the YTmate YouTube downloader. A remote-friendly Android TV experience and release alerts extend the service across screens.

**Highlights:** multi-source page parsing · Android TV remote navigation · Seedr integration · release alerts  
**Technology:** Django REST Framework, React, Android TV Leanback, Flutter, Node.js, PostgreSQL, Firebase Cloud Messaging  
[Live site](https://rsgmovies.com) · [API](https://rsg-movies.vercel.app) · [GitHub](https://github.com/shivaganesh22/rsgmovies)

### Auto-Send · Instagram automation

Auto-Send is an Instagram engagement tool that turns comments into public replies or direct messages. Creators configure response workflows and personalize message content, then can require a viewer to follow before selected links or downloads are sent. Incoming events are checked and deduplicated to avoid repeat replies. A dashboard shows message delivery and API response performance, while exportable activity history helps creators review campaigns and investigate failed sends.

**Highlights:** webhook verification · duplicate-event prevention · follow-gated delivery · analytics and audit history  
**Technology:** Django, Meta Graph API, webhooks, HMAC-SHA256, Alpine.js, Tailwind CSS  
[Live app](https://rsgflow.vercel.app) · [GitHub](https://github.com/shivaganesh22/Auto-Send)

### Price Tracker · E-commerce intelligence

Price Tracker helps shoppers monitor products and find daily deals across Amazon and Flipkart. Users can follow listings, compare current prices and discounts, and review how prices have changed over time. Each product can have a personal target price, so shoppers are notified by email or in the app when the price changes or reaches their chosen threshold. The dashboard brings watchlists, price history, and alerts together, making it easier to spot a deal without checking every store manually.

**Highlights:** product watchlists · price history · target-price alerts · daily deals  
**Technology:** React, Django REST Framework, Firebase, web scraping  
[Live app](https://rsgtracker.vercel.app) · [API](https://rsg-price.vercel.app) · [GitHub](https://github.com/shivaganesh22/price-tracker)

### AUpulse · Automated attendance

AUpulse is an automated attendance system that connects classroom CCTV footage with student records and the class timetable. It uses real-time facial data to mark enrolled students present for the scheduled class, helping reduce manual effort and proxy attendance. The platform also lets administrators manage students, faculty, rooms, classes, and schedules. Students can review their attendance in the companion app, while administrators generate detailed reports and identify attendance shortages.

**Highlights:** timetable-linked attendance · student app · academic administration · attendance reports  
**Technology:** Flutter, OpenCV, Django REST Framework, Python, PostgreSQL  
[Live API](https://aupulse-api.vercel.app) · [GitHub](https://github.com/shivaganesh22/mini-project)

### Image Deduplication · AIMLA research

Image Deduplication is a Django platform for finding repeated and visually similar images in a collection. It compares images using pretrained ResNet, EfficientNet, and MobileNet models alongside hybrid matching methods, so resized, cropped, or adjusted copies can still be identified. Results show similarity percentages and flag likely duplicates for review. The tool also reports resource usage and estimated storage savings, helping users understand both the matches and the potential cost reduction. The work was presented at AIMLA 2025 as Paper #455.

**Highlights:** visual-similarity matching · duplicate review · resource reporting · published research  
**Technology:** PyTorch, Django, ResNet, EfficientNet, MobileNet, OpenCV, perceptual hashing  
[GitHub](https://github.com/shivaganesh22/major-project)
